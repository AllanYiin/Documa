# PDF Fixtures

Future fixtures should cover the nine Documa parsing risks:

1. Superscript, font changes, and inline emphasis.
2. Human reading order, including multi-column pages.
3. Non-text objects such as figures and charts.
4. Paragraph grouping across multiple visual rows.
5. Table recognition and structure normalization.
6. RAG/RLM-ready chunks with provenance.
7. Footnote marker and footnote body linking.
8. Table of contents parsing and linking.
9. Embedded images and chart crops as Pillow-compatible assets.
