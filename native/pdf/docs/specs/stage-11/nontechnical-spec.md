# Stage 11 白話規格：讓抽出的文字更接近人真正閱讀的內容

規格版本：1.2.0  
適用對象：使用這個工具抽取 PDF 文字、建立搜尋內容或檢查文件的人

## 這個階段要解決什麼

目前工具已能成功開啟兩份大型實際文件，也能抽出其中的中文與英文。不過，有些 PDF
把每個字分開擺放，工具若只看字的位置，可能把 `Artificial` 錯誤組成
`A r tificial`，也可能把「台灣政府」變成「台 灣 政 府」。

下一階段不只要求「有抽到字」，還要把下列事情分開判斷：

- 字本身是否正確。
- 字的先後順序是否正確。
- 字與字之間是否真的需要空白。
- 哪些換行來自文件，哪些是工具依位置補上的。
- 哪些文字是文件作者提供的替代文字。
- 哪些結果因文件資訊不完整，只能採用有限度的替代方式。

## 你可以選擇三種文字結果

| 模式 | 適合情況 | 會做什麼 | 不會做什麼 |
|---|---|---|---|
| 原始順序 | 要稽核文件內原本的文字順序 | 依文件記錄順序輸出 | 不依畫面位置補空白或重排 |
| 位置整理 | 想保留目前的近似排版結果 | 依字的位置分行與排序 | 不承諾等同人類閱讀順序 |
| 自動整理 | 一般搜尋、閱讀與建立索引 | 參考字的寬度、位置、語言與替代文字整理 | 不用影像辨識，也不猜看不懂的字形 |

舊有使用方式會繼續維持原本結果，不會在升級後突然改變。要使用新的自動整理能力，
必須明確選擇新方式。

## 文字判斷的優先順序

工具會依下列順序決定文字：

1. 如果文件作者為一整段內容提供替代文字，優先使用該段替代文字。
2. 如果文件有明確的字碼對照，依該對照輸出。
3. 如果對照缺少，但文件仍提供可辨識的字型名稱或編碼，採有限度的替代方式並提示。
4. 如果仍無法確認，輸出替代符號 `�`，不自行猜字。

若文件中的某一筆字碼對照損壞，工具只略過那一筆，不會讓整份文件完全失敗，也不會
擅自顛倒內容來湊出看似合理的字。

## 空白與換行規則

- 連續中文字、日文字或韓文字不會只因每個字分開定位就自動加空白。
- 英文等通常以空白分詞的文字，會參考字寬與字距判斷，不使用固定畫面距離。
- 文件原本已有空白時，不會再補第二個空白。
- 工具補上的空白與換行會被計數，讓你知道整理結果包含多少推測。
- 同一份文件、相同設定與相同版本，每次都必須得到相同結果。
- 遇到多欄、旋轉、重疊或直排文字而無法可靠判斷時，工具會保留較少的推測並提出提示。

## 兩份實際文件的完成標準

### AI Index 2026

- 能完整開啟 423 頁文件。
- 能驗證其中 45,151 個使用中的內容項目。
- 自動整理結果必須包含 `Artificial Intelligence Index Report 2026`。
- 不得再出現 `A r tificial`、`Int elligenc e` 或 `Inde x`。
- 文件缺少字碼資訊的地方仍會提示，不會把提示隱藏成「完全正確」。

### 台灣政府動畫宣導影片

- 能完整開啟 15 頁文件。
- 能驗證其中 1,317 個使用中的內容項目。
- 自動整理結果必須包含連續的「台灣政府動畫宣導影片」。
- 不得輸出成「台 灣 政 府 動 畫 宣 導」。
- 目前這份文件沒有抽取提示；升級後仍應保持為零。

## 你會看到哪些結果

一般純文字輸出仍只顯示文字，不會混入診斷內容。若選擇詳細結果，會另外看到：

- 每一頁抽到的文字。
- 帶位置的文字片段。
- 使用哪一種方式得到文字。
- 工具補了多少空白與換行。
- 有多少字使用替代方式。
- 有多少字無法確認而顯示 `�`。
- 是否有閱讀順序不確定的頁面。

## 使用流程

1. 提供 PDF 檔案。
2. 選擇「原始順序」「位置整理」或「自動整理」。
3. 工具先檢查文件結構與安全上限。
4. 工具取得字碼、字的位置與文件作者提供的替代文字。
5. 選擇自動整理時，工具再判斷分行、順序與空白。
6. 輸出文字；若文件資訊不完整，同時提供不影響純文字內容的提示。

## 檔案與隱私

- 工具不會自行上傳 PDF。
- 瀏覽器版本在本地頁面中處理傳入內容。
- 兩份測試文件不會直接放進公開專案。
- 測試只保存檔案指紋、頁數、應出現的文字與不應出現的錯誤片段。
- 若未提供私人測試文件，測試結果會明確標示「略過」，不會假裝已經測過。

## 限制與注意事項

- 這個工具不顯示 PDF 頁面畫面。
- 這個工具不辨識掃描圖片中的文字。
- 這個工具不能開啟需要密碼的文件。
- 表格、多欄、重疊、旋轉與直排文字仍可能沒有唯一閱讀順序。
- 文件作者若沒有留下可靠字碼資訊，任何工具都不一定能還原原字。
- 自動整理的目標是改善一般搜尋與閱讀，不宣稱重建原始版面。
- PDF 2.0 的所有新規則尚未列為本階段的完整保證。

## 完成後你會得到什麼

- 一份較適合閱讀與搜尋的自動整理文字。
- 一份忠於文件記錄順序的原始文字。
- 一份保留舊版行為的位置整理文字。
- 清楚區分確定內容、替代內容與工具推測的詳細結果。
- 四種使用方式都一致的文字與提示。
- 不會因改善文字品質而放棄既有安全上限。

## 不會在這一階段出現的功能

- PDF 頁面顯示與縮圖。
- 掃描圖片的文字辨識。
- 密碼解鎖。
- 修改或另存 PDF。
- 猜測並修復嚴重損壞的文件。
- 依賴其他現成 PDF 解析工具完成核心工作。
